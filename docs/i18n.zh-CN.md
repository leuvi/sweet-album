# 国际化

[English](./i18n.md) | [简体中文](./i18n.zh-CN.md)

默认英文，内置简体中文。

```js
new SweetAlbum('#album', { locale: 'zh-CN' })
album.setLocale('en') // 运行时切换 —— 分组头、刻度、提示文案都会跟着变
```

## 覆盖单条文案

`messages` 会合并到所选语言包之上，因此改一条和改全部一样方便：

```js
new SweetAlbum('#album', {
  locale: 'zh-CN',
  messages: {
    empty: '这里还没有照片',
    favorite: '标星',
    unfavorite: '取消标星',
  },
})
```

## 新增语言

没有什么"语言注册表"需要扩展 —— 一个完整的 `messages` 对象本身就是一门语言：

```js
import { en } from 'sweet-album'

const fr = {
  ...en,
  photos: 'photos',
  photo: 'photo',
  selected: 'sélectionné(s)',
  selectAll: 'Tout sélectionner',
  deselectAll: 'Tout désélectionner',
  clearSelection: 'Effacer la sélection',
  favorite: 'Ajouter aux favoris',
  unfavorite: 'Retirer des favoris',
  empty: 'Aucune photo',
  loading: 'Chargement…',
  loadFailed: 'Échec du chargement',
  close: 'Fermer',
  prev: 'Précédent',
  next: 'Suivant',
  zoomIn: 'Zoom avant',
  zoomOut: 'Zoom arrière',
  rotateLeft: 'Rotation à gauche',
  rotateRight: 'Rotation à droite',
  actualSize: 'Taille réelle',
  fitToWindow: 'Ajuster à la fenêtre',
  months: ['janvier', 'février', /* … */],
  monthsShort: ['janv.', 'févr.', /* … */],
  dateHeader: ({ year, month, day }) => `${day} ${fr.months[month - 1]} ${year}`,
}

new SweetAlbum('#album', { messages: fr })
```

## 日期分组头

`dateHeader` 拿到的是年月日三个数字，返回分组标题字符串，所以你可以用 `Intl`
或任何格式化方案：

```js
const fmt = new Intl.DateTimeFormat('zh-CN', { dateStyle: 'full' })

new SweetAlbum('#album', {
  messages: {
    dateHeader: ({ year, month, day }) => fmt.format(new Date(year, month - 1, day)),
  },
})
```

右侧时间轴在年份旁边显示的是 `monthsShort`，所以那几项请保持简短。

## 文案清单

| 键                             | 用在哪里                          |
| ------------------------------ | --------------------------------- |
| `photos` / `photo`             | 顶部栏照片数                      |
| `selected`                     | 顶部栏，有选中项时                |
| `selectAll` / `deselectAll`    | 勾选圈的悬浮提示                  |
| `clearSelection`               | 顶部栏的清空按钮                  |
| `favorite` / `unfavorite`      | 收藏心的悬浮提示                  |
| `empty`                        | 空状态                            |
| `loading` / `loadFailed`       | 预览器状态                        |
| `close` / `prev` / `next`      | 预览器控件                        |
| `zoomIn` / `zoomOut`           | 预览器工具栏                      |
| `rotateLeft` / `rotateRight`   | 预览器工具栏                      |
| `actualSize` / `fitToWindow`   | 预览器工具栏                      |
| `dateHeader`                   | 日期分组头                        |
| `months` / `monthsShort`       | 时间轴刻度                        |

内置语言包也一并导出，方便查看或二次加工：

```js
import { locales, resolveMessages } from 'sweet-album'
// locales.en、locales['zh-CN']
```
