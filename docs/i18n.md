# Internationalization

[English](./i18n.md) | [简体中文](./i18n.zh-CN.md)

English is the default. Simplified Chinese ships built in.

```js
new SweetAlbum('#album', { locale: 'zh-CN' })
album.setLocale('en') // at runtime — relabels headers, ticks and tooltips
```

## Overriding strings

`messages` is merged over the chosen locale, so you can override one string or
all of them:

```js
new SweetAlbum('#album', {
  locale: 'en',
  messages: {
    empty: 'Nothing here yet',
    favorite: 'Star',
    unfavorite: 'Unstar',
  },
})
```

## Adding a language

There is no locale registry to extend — a full `messages` object *is* a locale:

```js
import { en } from 'sweet-album'

const fr = {
  ...en,
  photos: 'photos',
  photo: 'photo',
  selected: 'sélectionné(s)',
  selectAll: 'Tout sélectionner',
  deselectAll: 'Tout désélectionner',
  clearSelection: 'Effacer la sélection',
  favorite: 'Ajouter aux favoris',
  unfavorite: 'Retirer des favoris',
  empty: 'Aucune photo',
  loading: 'Chargement…',
  loadFailed: 'Échec du chargement',
  close: 'Fermer',
  prev: 'Précédent',
  next: 'Suivant',
  zoomIn: 'Zoom avant',
  zoomOut: 'Zoom arrière',
  rotateLeft: 'Rotation à gauche',
  rotateRight: 'Rotation à droite',
  actualSize: 'Taille réelle',
  fitToWindow: 'Ajuster à la fenêtre',
  months: ['janvier', 'février', /* … */],
  monthsShort: ['janv.', 'févr.', /* … */],
  dateHeader: ({ year, month, day }) => `${day} ${fr.months[month - 1]} ${year}`,
}

new SweetAlbum('#album', { messages: fr })
```

## Date headers

`dateHeader` receives the calendar parts and returns the group label, so you can
use `Intl` or any formatter you like:

```js
const fmt = new Intl.DateTimeFormat('de-DE', { dateStyle: 'long' })

new SweetAlbum('#album', {
  messages: {
    dateHeader: ({ year, month, day }) => fmt.format(new Date(year, month - 1, day)),
  },
})
```

`monthsShort` is what the right-edge scrubber shows next to each year, so keep
those entries short.

## Message reference

| Key                            | Used by                                     |
| ------------------------------ | ------------------------------------------- |
| `photos` / `photo`             | Top bar count                               |
| `selected`                     | Top bar, when a selection exists            |
| `selectAll` / `deselectAll`    | Tooltips on selection circles               |
| `clearSelection`               | Top bar clear button                        |
| `favorite` / `unfavorite`      | Heart tooltip                               |
| `empty`                        | Empty state                                 |
| `loading` / `loadFailed`       | Viewer status                               |
| `close` / `prev` / `next`      | Viewer controls                             |
| `zoomIn` / `zoomOut`           | Viewer toolbar                              |
| `rotateLeft` / `rotateRight`   | Viewer toolbar                              |
| `actualSize` / `fitToWindow`   | Viewer toolbar                              |
| `dateHeader`                   | Day group headers                           |
| `months` / `monthsShort`       | Timeline scrubber ticks                     |

The built-in packs are exported if you want to inspect or extend them:

```js
import { locales, resolveMessages } from 'sweet-album'
// locales.en, locales['zh-CN']
```
